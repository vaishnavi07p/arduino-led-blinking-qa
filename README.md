# Arduino LED Blinking Using Arduino Uno

## 1. Project Description
This project demonstrates a basic embedded system using an Arduino Uno. The built-in LED turns ON and OFF at one-second intervals.

## 2. Objective
To understand digital output control, Arduino programming, code documentation, and software quality assurance using GitHub.

## 3. Components Required
- Arduino Uno
- USB cable
- Arduino IDE
- Computer

## 4. Working Principle
The setup() function configures the LED pin as an output. The loop() function turns the LED ON, waits for one second, turns it OFF, and waits for another second. This process repeats continuously.

## 5. Expected Output
The built-in LED blinks continuously with approximately one second ON and one second OFF.

## 6. Quality Assurance
GitHub Issues are used to record potential problems, analyze their causes, document solutions, and track their resolution.

## 7. Tools Used
- Arduino IDE
- Arduino Uno
- GitHub Repository
- GitHub Issues

## 8. Conclusion
This project demonstrates basic embedded programming and the use of GitHub for code documentation, QA issue tracking, and project management.
